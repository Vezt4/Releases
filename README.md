# Vezta — Releases

APKs do app **Vezta** para Android, para quem quer instalar direto, sem passar pela Google Play.

## Baixar

[**Baixar a versão mais recente (vezta.apk)**](https://github.com/Vezt4/Releases/releases/latest/download/vezta.apk)

Versões anteriores ficam na aba [Releases](https://github.com/Vezt4/Releases/releases).

## Instalar

1. Baixe o `vezta.apk` no celular.
2. Abra o arquivo. O Android vai pedir para permitir a instalação de apps desta fonte: permita.
3. Pronto. Abra o Vezta e crie sua conta.

## Bom saber

- Pelo APK, as atualizações **não chegam sozinhas**: baixe a nova versão aqui quando sair.
- O app está em **teste fechado na Google Play**. Para instalar pela Play e receber atualizações automáticas,
  entre no teste pelo [site do Vezta](https://vezta.app/#teste) ou pelo
  [BrTesters](https://brtesters.app/apps/details?id=com.vezta.app).
- O APK e a versão da Play são assinados com chaves diferentes. Para trocar de um para o outro, desinstale o
  app antes.
